# Identifier validation by digit rotations

Second midterm of *Estructuras de Datos y Algoritmos II* (UAX, December 2024). Given a list of fixed identifiers and a list of variable ones, the script generates every cyclic rotation of each variable identifier, compares it digit by digit with the fixed ones that share the first digit, and counts how many times a comparison switches between match and mismatch to decide which identifiers validate.

## Run

```bash
python identificadores.py
```
